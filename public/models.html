Server Details ("Server Inside") - UI Design Models

Select your preferred design model below. Click any image to view in full resolution.

Option 1: Cyber Ops Command Center Datadog & Grafana Style

4 Radial Dials: Glowing circular gauges for CPU (14%), RAM (30%), Disk (/dev/sda1 - 18%), and Network I/O (12.4 MB/s).
Real-Time Heartbeat Waveform: Glowing ECG line chart with live telemetry pulses and range selector.
Live Process Table: Browser-native htop inspector with PID, User, CPU%, Mem%, and Commands without needing to SSH.
Docker Container Health: Real-time container statuses, image versions, and runtime health.

Option 2: Cloud Native Cockpit Azure Monitor & CloudWatch Style

Correlated Area Charts: Dual-axis graphs overlaying CPU Load vs RAM Pressure vs Disk IOPS over time.
Storage Partition Breakdown: Visual disk usage progress bars for root (/), /var/log, and /data with available space.
Hardware Ecosystem Right Rail: Azure VM SKU, vCPUs, NIC throughput, and container allocation quotas.
Incident History Timeline: Automated threshold alert history and diagnostic logs.

Option 3: Terminal-Centric DevOps Deck Warp & Vercel Infra Style

50/50 Split Cockpit: Left side displays compact telemetry HUD (per-core CPU bars, stacked RAM bar, Disk IOPS).
Embedded Web-SSH Terminal: Right side features an active interactive Linux terminal session right on the page.
One-Click CLI Pills: Fast command shortcuts for htop, df -h, docker ps, journalctl -f.
Firewall & Port Security Matrix: Active UFW rule matrix showing open ports (22, 80, 443, 2375).
